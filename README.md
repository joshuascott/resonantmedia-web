# Resonant Media Technologies

Single-page site for [resonantmedia.com](https://www.resonantmedia.com). The studio builds applied AI and agentic systems. AI consulting is [Idea Collaborative](https://ideacollaborative.com/).

The 2014–2015 blog is retired. Those posts were about tools the studio no longer leads with, and a second writing channel would sit beside Idea Collaborative’s, which is already active.

## Develop

```sh
npm install
npm run dev
```

```sh
npm run build
```

`dist/` is a static site. Deploy that folder.

Old paths such as `/blog` and `/who-we-are` redirect to the new page.
